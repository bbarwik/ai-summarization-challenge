## **Open-Source and Community Projects**

- **Khoj:** A self-hostable personal AI "second brain" that chats with any local or cloud LLM (GPT, Claude, Llama, etc.) to answer questions using your documents, notes, and web pages  $13$ . It supports creating custom agents, RAG-style semantic search, summarization, image generation, and even integrations (Obsidian, Emacs, WhatsApp, etc.), all running privately on your machine  $13$ .
- Quivr: An opinionated open-source RAG tool for building AI assistants. Quivr ingests various file types (PDF, markdown, HTML, etc.) and works with any LLM to create a "second brain" chatbot over your knowledge [14](https://github.com/QuivrHQ/quivr#:~:text=Quivr%20,Empowered%20by%20Generative%20AI). It handles indexing, vectorization, and querying so developers can focus on higher-level features.
- **Graphiti:** A framework to build dynamic, temporal knowledge graphs for AI agents [[15](https://github.com/getzep/graphiti#:~:text=Graphiti%20is%20a%20framework%20for,aware%20AI%20applications)]. Instead of traditional RAG, Graphiti continuously integrates new user interactions and data into a coherent graph, allowing efficient historical and semantic queries. It powers state-of-the-art agent memory layers (e.g. Zep) by autonomously updating and querying evolving knowledge  $(15)$  $(15)$  $(15)$ .
- **· AutoAgent & Auto-Deep-Research:** An open-source agent framework and example app. AutoAgent (formerly MetaChain) lets users create LLM-based agents and workflows via natural language alone, with a built-in vector store and multi-LLM support  $(1)$  $(1)$  $(1)$ . On this foundation, Auto-Deep-Research provides a ready-to-use personal AI assistant (a zero-config research-agent) as an open alternative to proprietary tools [2](https://github.com/HKUDS/Auto-Deep-Research#:~:text=Welcome%20to%20Auto,Research%2C%20based%20on%20AutoAgent%20framework). Both emphasize extensibility and use cases like deep document research or coding assistance.

**Mem0:** An open-source memory system that gives AI agents persistent, contextual long-term • memory  $\beta$ . It combines LLM-based extraction with a dual storage (vector + graph) architecture, automatically extracting important facts from conversations and updating them over time. Mem0 claims significantly higher accuracy and lower latency/cost than OpenAI's memory API on benchmarks [3](https://docs.mem0.ai/overview#:~:text=Introduction). It's available as managed cloud API or an open-source library for local deployment.

#### **Commercial AI Platforms and Startups**

- **Taskade:** A collaborative productivity suite branded as an "AI Second Brain" [[4](https://www.taskade.com/ai/second-brain#:~:text=A%20Collaborative%20AI%20Second%20Brain)]. It unifies to-do lists, notes, mind maps, and real-time collaboration with AI chat. Taskade's AI-powered tools can outline tasks, generate content, and supercharge team workflows within shared workspaces  $\frac{4}{3}$  $\frac{4}{3}$  $\frac{4}{3}$ .
- Kortex: A commercial note- and idea-management app with AI. Kortex centralizes your highlights, outlines, and past writing, letting you ask an AI ("kAI") for summaries, advice, or content prompts . It markets itself as "If Google Docs, Notion, and Obsidian had a baby" – focusing on writing and [5](https://www.kortex.co/#:~:text=The%20AI%20Powered%20Second%20Brain) idea synthesis with AI assistance  $\begin{bmatrix} 5 \end{bmatrix}$  $\begin{bmatrix} 5 \end{bmatrix}$  $\begin{bmatrix} 5 \end{bmatrix}$ .
- **Dust:** An enterprise agent platform for building AI workflows. Dust lets organizations create AI agents connected to internal knowledge bases (e.g. CRM, tickets, docs) to automate analysis and actions. For example, teams can build customer-support bots that answer from company manuals or sales agents that analyze deal pipelines, all without heavy engineering. This SaaS connects models to data to "transform how work gets done"  $6$ .
- **Spheria AI:** A startup offering personalized AI "clones." Using a no-code interface, you feed Spheria your own content (social posts, writing, videos), and it generates a private AI assistant infused with your knowledge and style <sup>[7](https://spheria.ai/?ref=hackernoon.com#:~:text=What%20is%20Spheria%3F)</sup>. The result is a "virtual brain" that can answer questions as if it were you. Privacy and data ownership are core: each user gets a separate encrypted vector DB of their data $\sqrt{7}$  $\sqrt{7}$  $\sqrt{7}$ .
- **Recapio:** A knowledge-capture platform. Recapio helps users build a personal knowledge base by summarizing content from the web and media. It can extract and organize key points from articles, YouTube videos, or notes into libraries, and then allow you to chat with that curated repository. In effect, it's an AI archive that "evolves with you," letting you query your collected information.
- **· Zep Memory:** A commercial AI memory service aimed at agent developers. Zep ingests streams of messages and related data, fusing them into a temporal knowledge graph so chatbots can recall past facts accurately. According to Zep, this approach can **double** recall accuracy while reducing cost/latency for long-term context [8](https://www.getzep.com/#:~:text=Zep%20powers%20AI%20agents%20with,user%20interactions%20and%20business%20data). It exposes a memory API for applications to retrieve personalized user info from history in a single call.

## **Wearable Personal AI Memory Assistants**

- **Bee (Bee Computer):** A wearable assistant in a pendant form factor. Bee continuously listens to your environment and conversations (with user permission) and uses onboard AI to tag and summarize experiences. It then surfaces "takeaways," suggested tasks, reflections, and daily highlights via its app or voice queries <sup>[9](https://www.bee.computer/#:~:text=Bee%20turns%20your%20moments%20into,meaning)</sup>. In essence, Bee acts as an always-on second brain that passively records your day.
- **· Limitless AI (Pendant):** A clip-on recording device paired with cloud AI. The "Pendant" passively records speech and sounds from your day and builds a searchable log. You can later ask Limitless's AI questions about past conversations ("What did Alex say about the project?") or generate to-do lists and reminders from recorded audio. It boasts long battery life and privacy controls (encrypted data, user can "bookmark" moments) to serve as an external memory bank <sup>[10](https://www.limitless.ai/#:~:text=The%20world%E2%80%99s%20most%20wearable%20AI,ask%20your%20personalized%20AI%20anything)</sup>.

• Memoro (MIT Media Lab): An academic prototype for a personal memory aid [[11](https://www.media.mit.edu/projects/memoro/overview/#:~:text=People%20have%20to%20remember%20an,into%20daily%20life%20and%20conversations)]. Memoro is a wearable microphone that continuously captures the user's real-world audio. It then uses an AI agent to categorize and index interactions. Later, when the user needs to recall something (e.g. "what did I say about my vacation idea?"), Memoro infers context and presents relevant snippets or reminders. In studies, it helped users feel more confident in recalling information while preserving conversational flow [11](https://www.media.mit.edu/projects/memoro/overview/#:~:text=People%20have%20to%20remember%20an,into%20daily%20life%20and%20conversations).

## **Emerging Platforms and Research Initiatives**

**CosmOS (Humane AI OS):** An emerging context-aware operating system by the company Humane • (known for the AI Pin). CosmOS treats personal memory and identity as core OS layers  $12$  . It provides developers with an SDK that includes APIs for accessing the user's personal knowledge graph and identity profile (with privacy controls). The goal is to enable apps across devices to leverage the full span of a user's private data ("what you've seen, said, and heard") in a secure, on-device AI-powered ecosystem <sup>[12](https://humane.com/cosmos#:~:text=Libraries%20for%20integrating%20with%20CosmOS%E2%80%99,personal%20data%20securely%20and%20efficiently)</sup>.
